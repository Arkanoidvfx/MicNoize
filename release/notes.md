# Mic Noize 0.3.12

**Луп запускается при включении.** Если виртуальный микрофон работает и на сетке есть ноты, переключатель «Луп» сразу начинает воспроизведение. После рисования и стирания нот трек обновляется при отпускании мыши. «Стоп» выключает воспроизведение и луп, сохраняя выбранную длину.

**Ноты без ускорения звука.** Высота по вертикали теперь меняется с сохранением исходной длительности сэмпла. Короткие звуки в протянутой ноте повторяются в ритме шагов BPM, а не десятки раз в секунду. Воспроизведение и экспорт WAV используют одинаковую обработку.

Для передачи в Discord выберите виртуальный микрофон Mic Noize входом. Переключатель «Слышать самому» включает прослушивание через наушники при работающей обработке микрофона.

**Проверено:** нативные аудиопроверки, Rust release-тесты и сборка. **Не проверено:** прослушивание человеком в физических наушниках и Discord, действия мышью на пользовательском устройстве.
