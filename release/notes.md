# Mic Noize 0.4.51

- При открытии окна из трея, после сворачивания или возврата из другого приложения индикаторы громкости больше не показывают последнее значение перед уходом в фон — они сразу показывают текущий уровень. Раньше это выглядело так, будто секунду назад был громкий звук.

Не проверено: вживую в окне (проверено автотестами).
