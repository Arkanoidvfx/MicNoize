# Mic Noize 0.4.10

Исправлены тяжёлое перетаскивание и задержка ползунков при работающих индикаторах звука. При регулировке окно рисуется одним проходом: движение края и живые индикаторы больше не заставляют повторно рисовать десятки перекрывающихся областей. Это работает и при медленной доводке внутри одного шага, включая гейт на полоске «После».

Движение мыши теперь сразу запрашивает ближайший кадр, без дополнительного ожидания 16 мс. Частые события по-прежнему объединяются до последнего значения за кадр. Shift, точность, отпускание мыши и сохранение последней позиции при потере фокуса сохранены.

Прошли 97 Rust-тестов и Clippy. Уточнённый тест с изменяющимися индикаторами воспроизвёл кадры до 164 мс по p95 при масштабе 150%; после исправления p95 составляет 9,5 мс. При 200% среднее — 10,8 мс, p95 — 18,6 мс. Это замер CPU-отрисовки с синтетическим вводом; фактический FPS вывода Windows и физическая мышь отдельно не измерялись.
