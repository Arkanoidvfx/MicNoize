# Mic Noize 0.4.43

- Блок «Повтор последнего» на странице «Эффекты» стал аккуратнее: записи идут по две в ряд (время больше не наезжает на кнопки), у каждой круглая кнопка воспроизведения, которая подсвечивается, пока запись играет, а прогресс идёт тонкой полоской по нижнему краю.
- «В саундпад» теперь сначала спрашивает название и раздел. Поле уже заполнено сгенерированным именем вида «Запись 2026-10-26 17-43-59»: можно сразу напечатать своё или просто нажать Enter. Раздел можно выбрать из своих разделов саундпада, по умолчанию — открытый сейчас. Esc или «Отмена» закрывает форму без сохранения.
- Меню сохранения и форма открываются на месте записей, поэтому окно не прокручивается даже в минимальном размере.

Не проверено: ввод названия и выбор раздела в установленной программе (проверено автотестами и снимками экрана), сохранение, когда папка саундпада ещё не выбрана.
