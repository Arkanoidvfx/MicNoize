# Mic Noize 0.4.1

Исправлено аварийное завершение при запуске обработки через виртуальный микрофон TAG после обновления 0.4.0. Рабочие буферы звука теперь выделяются отдельно от стека аудиопотока; новые эффекты и сохранённые настройки остаются доступны.

Проверено: регрессия переполнения стека, нативные проверки эффектов и ABI, реальный маршрут микрофон → NVIDIA → TAG без потерь и разрывов. Субъективное качество новых эффектов и полный физический прогон WASAPI не проверялись.
