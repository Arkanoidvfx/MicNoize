# Mic Noize 0.4.39

- Отчёт разработчику («Отправить логи разработчику») и «звук для разработчика» теперь показывают, как идут данные в виртуальный микрофон: сколько звука фоновый компонент уже записал и сколько Windows ещё не забрала. Это нужно, чтобы найти причину роботизированного голоса, который у некоторых пользователей появляется после включения компьютера. Если голос звучит роботом, включите прослушивание «С шумодавом», подождите 10–20 секунд и нажмите кнопку отправки логов.
- Обработка звука не изменилась: новые данные только собираются для отчёта и не влияют на голос.

Проверено на RTX 3090: тесты движка, проверка памяти AddressSanitizer для всех компонентов, включая фоновый, и тесты интерфейса. Новая диагностика ещё не проверялась в живой работе: её покажут первые отчёты после обновления. Само искажение этим обновлением не исправляется.
