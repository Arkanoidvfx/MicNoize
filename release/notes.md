# Mic Noize 0.4.2

Страница «Эффекты» теперь разделена на «Голос вживую» и «Фразы и повторы». Переключатель показывает, если эффект из скрытой группы сейчас звучит; выбранная группа сохраняется. Все настройки эффектов и блок прослушивания помещаются в окне без прокрутки. Версия в заголовке стала немного крупнее.

Глитч при наведении на «by ARKANOID» обновляет только изменившиеся части изображения и больше не перерисовывает всё окно на каждом кадре. Снимок берётся по фактическому размеру окна.

Проверено: 84 теста Rust прошли, Clippy чистый, проверены снимки обеих групп и замер перерисовки. Поведение в живом окне после установки, субъективное качество эффектов и полный физический прогон WASAPI не проверялись.
