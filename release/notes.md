# Mic Noize 0.3.13

**Окончание обновления без чёрной области.** После «Запускаем Mic Noize» окно обновления больше не пропадает с чёрной областью за ним: новая версия открывается прозрачной точно поверх окна обновления, рисует ту же карточку, и только потом окно обновления закрывается, а программа вырастает из карточки. Пока идёт переход, анимации появления и закрытия окон Windows для окна программы выключены: в них прозрачность вокруг карточки не работала.

**Переход с 0.3.12:** используйте обновление в программе. Окно обновления показывает копия прежней версии, поэтому её собственное закрытие может ещё мелькнуть по-старому; полностью новый переход виден со следующего обновления. Кнопка «Настройки → Диагностика → Проверить анимацию обновления» проигрывает весь переход этой версией сразу. Пакет текущей версии сохраняется для отката.

**Проверено:** автоматические проверки, release-сборка и упаковка. **Не проверено:** переход глазами при настоящем обновлении и в «Проверить анимацию обновления», несколько мониторов, отключение питания во время обновления.
