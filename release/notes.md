# Mic Noize 0.3.15

**Подбор шумоподавления под микрофон.** На странице «Шумодав» появилась панель «Подбор под микрофон»: программа просит несколько секунд тишины, затем короткую проверку голосом и выбирает мягкую силу, которая убирает фоновый шум. Результат сохраняется для выбранного микрофона. Его можно отменить кнопкой «Вернуть», а во время подбора — остановить. Для прослушивания своего голоса есть отдельная кнопка.

На новой установке обычная сила шумоподавления — 40 %, сила при удержании клавиши — 10 %. Сохранённые значения остаются прежними. Подбор не выставляет экспериментальную силу выше 100 %.

**Обновления.** Программа снова проверяет GitHub каждые 15 минут, в том числе когда скрыта в трее. После загрузки обновления карточка в левой колонке показывает его версию и короткую анимацию; версия установленной программы теперь видна в заголовке окна. В настройках осталась кнопка ручной проверки. Закрытый Discord больше не показывается как ошибка на странице эффектов.

**Проверено:** 82 Rust release-теста; 5 тестов пропущены. **Не проверено:** подбор на настоящем микрофоне и прослушивание человеком, плавность анимации в живом окне, длительная работа в трее и установка обновления по медленной сети.
