# Mic Noize 0.4.21

- Восстановление после установки или обновления больше не запускает внешнюю утилиту reg.exe: автозапуск восстановления управляется через Windows API. Устранён возможный источник ошибки «Не удаётся найти указанный файл».
- Если запуск всё же прервётся, окно ошибки и Logs/rust-ui-error.log укажут этап запуска. Ошибки открытия пакетов и копирования файлов восстановления содержат пути.

Причина сбоя конкретного ПК на 0.4.20 ещё не подтверждена. Целевой тест диагностики прошёл; повторные тесты при выпуске пропущены по запросу владельца. Запуск на проблемном ПК и живая установка не проверены.
