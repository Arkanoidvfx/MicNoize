# Mic Noize 0.4.23

- Исправлен подтверждённый сбой переустановки: «Открытие пакета ... full.nupkg: Не удаётся найти указанный файл». Старый журнал обновления больше не требует, чтобы полный пакет текущей версии обязательно лежал в кэше под заданным именем.
- Пакет ищется по версии. При пустом кэше программа сама скачивает официальный полный пакет, проверяет подпись и соответствие установленных файлов, сохраняет его и завершает прежний журнал. Настройки и пакеты отката сохраняются.
- Автоматический отчёт об ошибке до открытия окна из 0.4.22 остаётся доступен.

Первый запуск после переустановки с пустым кэшем требует интернет и может занять время на загрузку пакета. Целевая проверка восстановления прошла; полный повторный прогон пропущен. Запуск на проблемном ПК пока не проверен.
