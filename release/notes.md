# Mic Noize 0.4.3

Кнопка «Перезапустить» на карточке готового обновления теперь вдавливается и выпадает одним из четырёх способов. На её месте появляется щель с порывами ветра, а карточка показывает текущий этап подготовки. После анимации окно переходит к прежнему процессу обновления. Если перезапуск не состоялся, кнопка возвращается.

Конфетти при появлении обновления вылетает, тормозит и плавно падает. Предпросмотр в «Настройки → Диагностика → Карточка обновления» показывает новую анимацию без настоящего перезапуска.

Проверено: 85 тестов Rust прошли, Clippy чистый, снимки анимации осмотрены, замерена стоимость кадров. Настоящий перезапуск с обновлением, вид и плавность анимации на экране и слабые ПК не проверялись.
