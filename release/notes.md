# Mic Noize 0.4.14

- **Новые шрифты:** интерфейс набран шрифтом Onest, нарисованным в первую очередь под кириллицу. Цифры, время записей, заголовки страниц и логотип — игровой Russo One. У каждого вида текста свой стиль: заголовки карточек одного размера, шапки колонок отделены от подсказок, кнопки и выбранный раздел выделены начертанием. Шрифты встроены в программу, устанавливать ничего не нужно.
- **Повтор последнего:** все шесть записей теперь одинаковые компактные плитки по три в ряд, без большой карточки и прокрутки. Играющая запись подсвечена, полоска под ней показывает прогресс (при реверсе — справа налево). Длительность записи в плитке больше не показывается.
- **Слышать эффекты** включено по умолчанию. При обновлении оно включится один раз, дальше ваш выбор сохраняется.
- **Громкость эффектов:** так теперь называется ползунок громкости эффектов Discord на странице эффектов.

Не проверено: внешний вид в живом окне после установки обновления (проверялись снимки, отрисованные тем же движком), окно 620×440, окно обновления — оно покажет новые шрифты только со следующего обновления.
