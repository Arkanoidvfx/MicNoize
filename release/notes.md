# Mic Noize 0.4.9

Исправлено рывками выглядевшее перетаскивание всех ползунков. Светящийся край и бирка теперь движутся плавно по всей шкале, включая движение внутри одного сегмента или шага высоты тона. Числа и звук сохраняют заданный шаг; Shift по-прежнему даёт точную доводку.

Частые события курсора объединяются до последнего значения на кадр. Программа больше не перестраивает весь интерфейс на каждый пакет мыши. Поток событий не отодвигает срок отрисовки; отпускание мыши и потеря фокуса сразу сохраняют последнюю позицию. Гейт на полоске «После» использует ту же обработку.

Прошли 96 Rust-тестов и Clippy. Проверены поток 1000 событий, смена Shift, дробные движения, колесо, отпускание и потеря фокуса. Полный синтетический путь ввода, применения значения и CPU-отрисовки при 200% масштаба занимает в среднем 6,8 мс на кадр. Проверки анимаций обновления при 100–200% также прошли. Физическая мышь и фактический FPS вывода Windows не измерялись.
