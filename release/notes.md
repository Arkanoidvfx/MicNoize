# Mic Noize 0.4.46

- Исправлен треск после 0.4.45 на компьютерах без RTX (шумодав DeepFilterNet на процессоре, например GTX 1080 Ti). В 0.4.45 модель была переведена в отдельный поток с ограничением ожидания на блок, и при времени кадра около этого ограничения блоки чередовались с шумодавом и без него. Модель снова считается как в 0.4.44.
- Остальные изменения 0.4.45 сохранены: разрыв захвата не сбрасывает шумодав, опоздавший блок на видеокарте стоит только себя, единичный сбой кадра DeepFilterNet не останавливает обработку.

Не проверено: сам треск не воспроизводился на машине разработчика (есть только RTX); подтверждение ожидается от пользователя с GTX 1080 Ti.
