# Mic Noize 0.4.24

- Исправлен отказ «TAG exclusive policy write access: HRESULT 0x80070005», из-за которого после установки виртуального микрофона не запускалась обработка и не было звука. Настройка общего режима записывается через Windows PolicyConfig без запуска приложения от администратора, с проверкой результата.
- Во время установки драйвера и ожидания появления устройства больше не висит красная ошибка «TAG host initializing or waiting for driver». Ошибки, требующие действия, остаются видимыми.
- Новый TAG-хост устанавливается вместе с приложением штатным обновлением. Настройки и идентификатор виртуального микрофона сохраняются.

На текущем ПК прошли запись настройки без повышения прав, проверка запрета эксклюзивного захвата и одновременный захват двумя обычными клиентами. Целевая проверка ожидания установки прошла. Полный повторный прогон пропущен; новый хост и звук на проблемном ПК, свежий endpoint и другие версии Windows пока не проверены.
