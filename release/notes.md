# Mic Noize 0.4.17

- **Отходящий провод микрофона больше не сбивает Discord.** Раньше, когда физический микрофон пропадал и появлялся снова, Discord сам переключался на него, и Mic Noize приходилось выбирать заново. Теперь, пока работает обработка, Mic Noize держит свой микрофон устройством ввода Windows по умолчанию.
- **Что сделать один раз:** в Discord → «Голос и видео» → «Устройство ввода» выберите **«По умолчанию»**. Тогда после переподключения микрофона Discord остаётся на Mic Noize.
- Пока идёт обработка, Mic Noize — микрофон по умолчанию для всех программ Windows; другой микрофон по умолчанию на это время выбрать нельзя.
- Не проверено вживую: выдёргивание провода с Discord на «По умолчанию».
