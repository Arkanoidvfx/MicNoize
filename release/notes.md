# Mic Noize 0.4.25

Для случая, когда приложение уже не открывается после отката: скачайте [архив восстановления и установки](https://github.com/Arkanoidvfx/MicNoize/releases/download/v0.4.25/MicNoize-Repair-Install-0.4.25.zip), распакуйте его и запустите `repair-install-0.4.25.cmd`. Он проверит хеши, штатно завершит собственный старый хост и откроет официальный Setup 0.4.25. Это освобождает файлы до установки. Настройки и установленный драйвер сохраняются.

- Исправлена гонка запуска фонового хоста: повторная проверка устройства больше не отменяет его ещё не завершённый запуск. Эта гонка могла вызвать ожидание, откат обновления и возврат ошибки старой версии.
- Setup после проверки нового подписанного комплекта согласованно переводит работу со старого собственного хоста на новый, даже если осталось незавершённое восстановление обновления. Настройки, драйвер и идентификатор виртуального микрофона сохраняются.
- В диагностике сохраняется исходная причина неудачи до отката и информация об ошибке Планировщика.
- Исправление записи политики TAG без повышения прав из 0.4.24 сохранено.

Полный повторный прогон пропущен. Прошли самопроверка поколения восстановления, целевая проверка readiness и проверка хешей помощника на Windows PowerShell 5.1 с отказом для повреждённого хоста. Живой переход хоста, гонка Планировщика и запуск на проблемном ПК пока не подтверждены.
