# Mic Noize 0.4.19

- **Исправлен запуск после незавершённой установки.** Обновление или откат больше не требуют готового виртуального микрофона, если основной runtime или TAG-драйвер ещё отсутствуют. Откроется интерфейс, где можно завершить их установку.
- **Исправлено восстановление после переустановки через Setup.** Если установлен другой полный выпуск, программа проверяет его подпись и файлы и завершает старый журнал обновления, сохраняя его для диагностики. Повреждённый или смешанный комплект не принимается.
- Ошибки распаковки показывают причину, код выхода и сообщения архиватора. «Отправить разработчику» включает ранние логи TAG, ошибки запуска и установки, версию Windows и архиватора, а также список отсутствующих логов.
- Если 0.4.18 закрывается с сообщением «TAG host initializing or waiting for driver», установите этот выпуск через Setup.exe. После открытия программы завершите загрузку компонентов и при необходимости нажмите «Установить» для виртуального микрофона, подтвердив запрос Windows.
- Проверено автоматическими тестами. Полный цикл переустановки на проблемном ПК, физический виртуальный микрофон и установка на Windows 10 пока не проверены.
